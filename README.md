# Програмна система «Готель»

Навчальний прототип програмної системи для пошуку та бронювання номерів у готелі.

## Опис проєкту

Програмна система «Готель» призначена для автоматизації основних процесів роботи готелю.
У прототипі реалізовано перегляд номерів, пошук, фільтрацію за статусом, створення бронювань, скасування бронювань і збереження даних у браузері через LocalStorage.

## Функціональні можливості

- перегляд списку номерів;
- відображення типу, ціни, опису та статусу номера;
- пошук номерів за типом;
- фільтрація номерів за статусом;
- бронювання вільного номера;
- введення імені, телефону та email клієнта;
- вибір дати заїзду та дати виїзду;
- автоматична зміна статусу номера на «Заброньований»;
- перегляд списку створених бронювань;
- скасування бронювання;
- збереження даних у LocalStorage;
- окрема сторінка з реєстром вимог;
- візуальний сценарій використання «Бронювання номера».
